# Shur-loc SEO Tools

WordPress plugin providing SEO and structured data tools for the Shur-loc website.

## Features

- Generates Schema.org `FAQPage` structured data for the Shur-loc FAQ page.
- Parses FAQ questions and answers from rendered page content.
- Outputs FAQ structured data as JSON-LD.
- Keeps FAQ parsing, schema generation, and WordPress integration separated and testable.

## Requirements

- WordPress
- PHP 8.0 or later

## Development

The plugin uses PHPUnit, PHPStan, and WordPress Coding Standards for automated testing and static analysis.

Plugin classes and tests use the `Shurloc\SEOTools` namespace.
